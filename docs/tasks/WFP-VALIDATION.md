# WFP: экспертная проверка

Высший приоритет до стабильного выпуска. Исполнитель: отдельный разработчик
с Codex и опытом WFP. Прочитать AGENTS/HANDOFF.
Границы: Native/, Policy/, Core.Tests/, evidence.
GUID и контракты не менять без согласования; GUI/installer не переписывать.

1. Сверить ABI/offsets, union, байтовый порядок, flags, время жизни appId/enum
   по актуальному Windows SDK.
2. Проверить перечисление boot-time/disabled/старых фильтров, атомарность
   замены/очистки и ошибки begin/add/commit/abort.
3. Подтвердить boot-time поддержку ALE и DHCP/loopback в VM:
   успешный Add не доказывает раннюю фильтрацию.
4. Подтвердить persistent provider без serviceName после старта BFE и
   отсутствие DISABLED. Разобрать противоречие Provider0/Object Management.
5. Проверить старые TCP/UDP, raw/forwarded и ответы входящих потоков:
   ALE_AUTH_CONNECT не обещает покрытие всех путей пакета.
6. Проверить обход через разрешённый локальный IP TUN на физическом интерфейсе,
   чужие hard permit и одинаковый приоритет sublayer.
7. Подтвердить, какой бинарник реально открывает сокет VPN.
   Наличие файла в каталоге не является атрибуцией соединения.

Вернуть diff/тесты и воспроизводимый VM-протокол с packet capture.
Предел гарантий сформулирован точно; неподтверждённое не отмечено успешным.
Дефект исправлен с тестом либо представлен конкретный план усиления API.
Рабочая сеть оператора не переключалась.
