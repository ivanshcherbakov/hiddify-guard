# Установщик: VM-приёмка

Границы: installer/, scripts/, workflows/, документация.
Изменения lifecycle CLI согласовать с владельцем Program.cs.

Проверить Windows 10/11, RU/EN, UAC, установку/обновление,
interactive highest task для правильного пользователя, --minimized,
запрет записи обычному пользователю в exe/config.

Проверить uninstall при ON и выключенном Hiddify. Искусственный ненулевой
cleanup должен остановить удаление и сохранить exe.
Проверить отсутствующий exe, повторную очистку, несколько пользователей
и удаление только задач этой установки.

Обновление не вызывает --disable/--uninstall-clean.
Не устанавливать программу и задачи на рабочем ПК.
Вернуть installer log, обезличенный Task XML, собственные WFP-объекты
до/после и хэши сборки.
