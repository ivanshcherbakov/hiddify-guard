# Диагностика: независимое ревью

Границы: Core/Diagnostics/, Discovery/ и тесты. Не ослаблять WFP
и не давать диагностическому exe исключение ради прохождения проб.

Проверить IP_UNICAST_IF/IPV6_UNICAST_IF, byte order, выбор NIC,
несколько физических сетей, IPv6 без gateway, отмену и таймауты.
Packet capture должен подтвердить физический путь, а не успех через VPN.
Проверить DNS ID/QR и невозможность назвать таймаут BlockObserved.

Внешние запросы допускаются только при явном запуске диагностики;
смена состояния в ходе теста означает неопределённый ответ.
Вернуть diff, unit-тесты, наблюдения TCP4/TCP6/DNS и ограничения покрытия.
Никаких VPN-секретов и пользовательского трафика в логах.
