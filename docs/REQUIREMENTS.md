# Принятые требования и уточнения

Основание: gemini-code-1795376732556.md и расширенный PDF
«Выбор VPN-клиента с Kill Switch», прежде всего этапы на страницах 6–9.
PDF — план разработки, а не доказательство свойств Windows, актуальности
других VPN и лимитов тарифов.

| Область | Решение |
|---|---|
| Среда | C#/.NET 8, Windows x64, WPF, минимум зависимостей |
| Ядро | WFP, стабильные GUID, persistent provider/sublayer |
| Политика | ALE_AUTH_CONNECT V4/V6, block=1, allow выше, sublayer=65535 |
| Загрузка | Отдельные boot-time BLOCK/loopback/DHCP и persistent полный набор; одна транзакция |
| Очистка | Все фильтры своего provider, включая boot-time/disabled/старые; затем sublayer/provider |
| Исключения | Loopback, DHCP, IP TUN и fallback, бинарники выбранной установки |
| LAN | RFC1918/link-local/локальные подсети, по умолчанию включена |
| Отключение | Только явно; нет Disable в shutdown/dispose/error/таймере |
| Поиск | Процессы, каталоги, HKLM/HKCU 32/64-bit, ручной путь |
| Обновление | Проверка путей, NetworkChange, таймер 2 с, атомарное обновление |
| Диагностика | Явные TCP4/TCP6/DNS/внешний IP, 3 с на шаг |
| UX | Большой переключатель, цветной щит, красный при отсутствии Hiddify |
| Lifecycle | Трей, mutex, --minimized, ручное подтверждение отключения |
| Язык | CurrentUICulture, RU/EN ResourceDictionary |
| Данные | ProgramData, атомарный JSON, ACL, лог 2 МБ + резервная копия |
| Установка | Inno 6, RU/EN/admin/x64, интерактивная elevated logon task |
| Удаление | Cleanup до файлов; ненулевой код отменяет удаление |
| Поставка | CI/Release, self-contained EXE, installer, ZIP, SHA256, MIT |

## Исправления неточных формулировок

- PERSISTENT и BOOTTIME нельзя объединять на одном фильтре.
- 0x80320003 — FILTER_NOT_FOUND. Provider/sublayer используют 0x80320005/07.
  Другие ошибки не проглатываются.
- "Ни байта никогда" не доказывается unit-тестами, весом sublayer или BFE-записью.
- Прямые пробы закреплены за физическим адресом и интерфейсом: обычный успех
  через VPN не должен считаться утечкой.
- Таймаут и отсутствие IPv6 не считаются успешной проверкой.
- Зелёный статус обозначает обнаружение, не проверенную доступность VPN.
- LAN и процессы Hiddify — намеренные исключения. Разрешение бинарника пока
  не ограничено IP/портами VPS и не доказывает владение VPN-сокетом.
- Автостарт — interactive token/highest для пользователя-администратора,
  не SYSTEM/session 0.
- InitializeUninstall отменяет удаление при ошибке cleanup;
  одного UninstallRun для проверки кода возврата недостаточно.
- Обход SmartScreen, выключение Defender и прогнозы лимитов Codex
  не включены в продуктовые инструкции.
