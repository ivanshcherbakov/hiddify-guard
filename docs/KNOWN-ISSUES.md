# Подтверждённые наблюдения для ревью

## HiddifyCoreEngine.exe и sing-tun

В актуальной установленной конфигурации Hiddify обнаружены:

- процесс HiddifyCoreEngine.exe, владеющий внешними соединениями VPN;
- адаптер tun0 с описанием sing-tun Tunnel;
- стандартные адреса 172.19.0.1/28 и fdfe:dcba:9876::1/126;
- выбранный IPv4-маршрут через tun0.

Текущий HiddifyDiscovery в основном приложении учитывает Hiddify/Wintun,
а его список приложений не содержит HiddifyCoreEngine.exe.
Из-за этого --diagnostics ошибочно возвращает tunDetected=false и неполный
allowlist. Включение основной программы без исправления способно заблокировать VPN.

Не считать установленную на диске CLI-обёртку владельцем транспорта:
нужна проверка пути реально запущенного процесса и его сокетов.
Исходники основной программы пока не исправлены; это приоритетное задание
для независимого ревью. Временный Windows Firewall-скрипт обнаруживает этот
вариант отдельно. Секреты VPN и адреса серверов в этот документ не включены.
